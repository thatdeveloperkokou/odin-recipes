# Odin-Recipes
This main reason for this project was to start my process in learning version control using `GIT` and learning the importance of `github` in web development.

## Project-Description
This project simply focuses on creating a simple recipe webpage.It focuses on two recipes as seen on the webpage [waakye](/recipes/Waakye.html) and [jollof rice](/recipes/jollofrice.html).The main function of the [homepage](/index.html) is to show the available recipes and link you to them through `relative links`. The recipe pages contain a simple structure of: 

1. **Recipe Title**
2. **Description**
3. **Ingredients**
4. **Steps**
